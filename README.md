# Лабораторная работа №2 — Классы, интерфейсы, пакеты и исключения

Костиков Артём Андреевич, МОА-251. Языки программирования (Java).

1. `Button` — счётчик нажатий
2. `Balance` — весы с двумя чашами
3. `Bell` — ding / dong
4. `OddEvenSeparator` — чётные и нечётные числа
5. `Table` — двумерная таблица чисел
6. Пакеты `geometry2d` (`Figure`, `Circle`, `Rectangle`), `geometry3d` (`Cylinder`) и `exceptions`
   (`InvalidDimensionException`, `InvalidFigureException`)

Запуск: `mvn compile exec:java`
